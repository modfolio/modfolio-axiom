## Content Strategy

### 포지셔닝

Axiom은 **응용 과학 그룹**이다.

아직 풀리지 않은 문제가 있는 곳 — 방위, 보안, 의료, 모빌리티, 에너지, 양자.
그 미지의 영역에 기술로 첫 발을 내딛는 것이 Axiom의 존재 이유다.

모회사 Modfolio의 "Visualize the Untold"를
Axiom은 "아직 지도에 없는 영역을 설계한다"는 언어로 실현한다.

Axiom은 개발 초기 단계의 자회사다.
직접적인 프로덕트는 Amberstella(셔틀 추적) 하나.
나머지 도메인은 앞으로 나아가고자 하는 방향이다.

따라서 콘텐츠는 **역량 주장이 아닌 포부**로 읽혀야 한다.
"이것을 합니다"가 아니라 "이곳을 향해 갑니다"의 톤.

### 기존 콘텐츠의 문제 (v1 대비)

| 문제 | 상세 |
|------|------|
| Untold DNA 부재 | "Applied Science & Engineering" — Modfolio 언어 체계와 단절 |
| Hero 제네릭 | "기술이 산업과 만나는 지점을 설계합니다" — 어디서든 쓸 수 있는 문장 |
| 포부의 부재 | 도메인 카드 + 제품 하나. 방향성이 읽히지 않음 |

### 페이지 구성

```
/ (홈)
└── /contact (연락처)
```

도메인 개별 페이지, About 페이지 없음.
개발 초기 자회사이므로 최소한의 구조 유지.

### 언어 규칙 (Hybrid)

| 영어로 유지 | 한글로 작성 |
|------------|-----------|
| 브랜드명 (Modfolio Axiom) | Hero 카피, Philosophy |
| 태그라인 (Engineering the Uncharted) | 도메인 Subtitle (키워드) |
| 도메인 타이틀 6개 | 섹션 Heading |
| 제품명 (Amberstella) | 제품 설명 문장 |
| CTA 버튼 텍스트 (Enter Portal) | SEO Description |
| 네비게이션 항목 (Domains, Contact) | 사업자 정보 |
| 도메인 라벨 (Mobility & Logistics 등) | |

원칙: 구조와 명명은 영어, 의미 전달은 한글.

### 금지 언어

| 표현 | 문제 |
|------|------|
| ~을 합니다, ~을 구축합니다 | 역량 주장. 아직 실체 없는 도메인에 부적절 |
| 불확실한 영역에 확실한 시스템을 | 과대 약속 |
| 도구, 포탈, 허브 | 유틸리티 회사 언어 |
| 솔루션을 제공합니다 | 컨설팅 회사 클리셰 |

### 카피라이팅 원칙

- "이것을 합니다" 대신 "이곳을 향해 갑니다"의 톤
- 포부는 담되, 구체적 역량 약속은 하지 않음
- 도메인 카드는 키워드 나열로 영역 암시
- Amberstella만 구체적 설명 (유일한 실체)
- B1 수준 어휘, 짧은 문장

## Home

### SEO

- **Title**: `Modfolio Axiom — Engineering the Uncharted`
- **Description**: `아직 풀리지 않은 문제에 기술로 답합니다. Modfolio의 응용 과학 그룹.`

### Hero

```
Eyebrow:  Modfolio Axiom
H1:       아직 풀리지 않은 문제가 있는 곳에서 시작합니다.
CTA:      Enter Portal
```

> "기술이 산업과 만나는 지점을 설계합니다" → 제네릭.
> "풀리지 않은 문제가 있는 곳" — 6개 도메인이 왜 존재하는지를 한 문장에.
> "시작합니다" — 이미 해냈다는 주장이 아닌, 지금 출발하는 포부.
> Untold = 아직 풀리지 않은 것. Uncharted = 아직 지도에 없는 곳.

### Philosophy

2-컬럼 레이아웃.

| 위치 | Label | Body |
|------|-------|------|
| 좌 | 우리가 보는 것 | 방위, 의료, 에너지, 양자. 산업의 가장 깊은 곳에는 아직 누구도 명쾌하게 답하지 못한 문제들이 있습니다. |
| 우 | 우리가 향하는 곳 | 그 문제 앞에서 기술이 할 수 있는 일을 찾습니다. 먼저 도착하는 것보다, 제대로 도착하는 것에 가치를 둡니다. |

> 좌: "우리가 믿는 것" 대신 "우리가 보는 것" — Axiom은 관찰자이자 탐험가.
>    "명쾌하게 답하지 못한 문제들" — Untold의 과학/공학 번역.
> 우: "우리가 만드는 것" 대신 "우리가 향하는 곳" — 아직 만들지 않았으니 방향을 이야기.
>    "먼저 도착하는 것보다, 제대로 도착하는 것" — 성급함이 아닌 정밀함. Axiom(자명한 진리)이라는 이름과 호응.

### Domains

```
Eyebrow:  Domains
Heading:  여섯 개의 미지 영역
```

> "여섯 개의 기술 영역" → "여섯 개의 미지 영역".
> "미지"가 Uncharted의 한글 표현. 도메인이 탐험 대상임을 암시.

| # | Title | Subtitle |
|---|-------|----------|
| 01 | Defense & Aerospace | 방위 시스템 · 위성 통신 · 항공우주 |
| 02 | Cybersecurity | 위협 탐지 · 암호화 · 보안 인프라 |
| 03 | Medical Technology | 의료 기기 · 바이오센서 · 임상 데이터 |
| 04 | Mobility & Logistics | 실시간 추적 · 경로 최적화 · 탑승 관리 |
| 05 | Energy & Materials | 신재생 에너지 · 배터리 · 신소재 |
| 06 | Quantum & AI | 양자 컴퓨팅 · AI 연산 · 차세대 알고리즘 |

> 카드 형태. 클릭/탭 동작 없음 (개별 페이지 없음).
> 호버 시 미세한 시각 피드백만.
> Subtitle은 키워드 나열로 영역을 암시하되 역량을 주장하지 않음.

### Product

```
Eyebrow:  First Step
Name:     Amberstella
Label:    Mobility & Logistics
Body:     셔틀의 실시간 위치를 추적하고, 탑승 경험을 개선합니다.
Link:     amberstella.com
```

> "First Product" → "First Step".
> 제품이라기보다, 미지의 영역을 향한 첫 걸음이라는 맥락.

### CTA

```
H2:       탐사는 이미 시작되었습니다.
Button:   Enter Portal
```

> "기술의 다음 접점을 탐색하세요" → 방문자에게 탐색을 요구하는 톤.
> "탐사는 이미 시작되었습니다" → Axiom 스스로의 선언. 방문자에게 요구하지 않음.
> "탐사" — Uncharted, 미지 영역, 도메인 탐험과 일관된 언어.
